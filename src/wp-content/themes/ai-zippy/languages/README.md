# Languages

Translation files (`.pot`, `.po`, `.mo`) for the `ai-zippy` textdomain.

Loaded by `AiZippy\Core\ThemeSetup::setup()` via `load_theme_textdomain()`.

Regenerate the template with WP-CLI from the repository root:

```
wp i18n make-pot src/wp-content/themes/ai-zippy src/wp-content/themes/ai-zippy/languages/ai-zippy.pot --domain=ai-zippy
```
